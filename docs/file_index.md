# Sunspire Online – Data File Index

This document tracks all JSON data files added to the public repository.  
It serves as a quick reference for structure, naming conventions, and what content lives where.

---

## Factions

| File | Region/Nation | Notes |
|------|---------------|-------|
| `data/factions/valeris_factions.json` | Valeris | Public-only factions (filtered from full data). |

---

## Sessions

| File | Scope | Notes |
|------|--------|-------|
| `data/sessions/main_campaign_sessions.json` | Campaign Timeline | Public-safe version of all campaign sessions (no DM notes). |

---

## Locations

| File | Scope  | Notes |
|------|--------|-------|
| `data/locations/world_nations.json`        | All Nations | List of all public-safe nations (top-level entries only). |
| `data/locations/valeria_locations.json`    | Valeria     | Regions, cities, and places associated with Valeria (includes Eldenhold). |
| `data/locations/mireholm_locations.json`   | Mireholm    | Regions, cities, and places associated with Mireholm. |
| `data/locations/sylvara_locations.json`    | Sylvara     | Regions, cities, and places associated with Sylvara. |
| `data/locations/big_titty_demon_island.json` | Big Titty Demon Island | Independent island region, not part of any nation. |
